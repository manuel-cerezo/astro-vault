# Assets

| File                    | Size        | Use                                                                         |
| ----------------------- | ----------- | --------------------------------------------------------------------------- |
| `banner.png`            | 2560 × 1280 | README header and GitHub social preview.                                    |
| `social.png`            | 2400 × 1350 | Image for posts on X, LinkedIn or Bluesky (16:9).                           |
| `poster.png`            | 1920 × 1080 | Video thumbnail with a play button, linked from the READMEs.                |
| `logo.png`              | 1024 × 1024 | Avatar or icon.                                                             |
| `astro-vault-promo.mp4` | 1920 × 1080 | 25-second overview (H.264, 30 fps, with music and sound effects).           |
| `theme-*.png`           | 2880 × 1800 | Real screenshots of the built-in pages: light, dark and phone (780 × 1688). |

The video and the stills are made with [Remotion](https://www.remotion.dev/) in [`video/`](./video), using the camera helper from [launch-video-kit](https://github.com/borjaperfra/launch-video-kit) by Borja Pérez. The screenshots come from `examples/pages`.
